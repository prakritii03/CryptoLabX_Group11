\# CryptoLabX\_GroupXX



\## Cryptography Laboratory (22CPP307)



CryptoLabX is a modular cryptanalysis and cryptography toolkit being developed as part of the Cryptography Laboratory course.



The objective of this project is to gradually develop a reusable framework for classical cryptography, cryptanalysis, mathematical operations, modern cryptography, and text analysis.

How to Run
Open PowerShell or Command Prompt.
Navigate to the project folder.
Run:
python main.py
Choose any option from the menu.

The Analyze option reads a text file from the datasets folder and displays useful statistics such as character count, word count, line count, unique characters, and letter frequency.

Logging

Every time the program runs and a menu option is selected, the information is stored in crypto.log along with the current date and time. This helps maintain a record of user activity.
